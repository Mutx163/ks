## 6. 两条注意事项（不是本批回归）

1. **未注册访客看不到赛季条**：排行榜在「没有同步码」时走「注册后即可参与排行」分支并 early-return，`_loadSeasonList/renderSeasonBar` 不会执行，所以访客页面没有赛季名/切换器。注册用户正常（本节表格与本地 B5 均验过）。若希望访客也看到赛季名，需要在该分支里补一次 `renderSeasonBar()`——属可选优化，建议登记。
2. **API 域名仍解析到 Cloudflare，且带 IPv6 AAAA**：`ks-api.mutx.ccwu.cc` → `2606:4700:3033::6815:266a` 等 + IPv4 `104.21.38.106/172.67.221.254`（CF）。本机 IPv6 不通，Node 直连会 10s 超时（浏览器能回退）。站点域名 `ks.mutx.ccwu.cc` 也仍有同两条 CF AAAA——**IPv6 用户仍可能被导回旧 CF**。建议清理这两条 AAAA（之前已提过，这次实测复现）。
