## 7. 风险

1. **重复导入**：接口不幂等，超时重发会产生 24 题。执行后先查 count。
2. **id 漂移**：若生产 maxId≠75（他人改动），新题 id 会跟着偏移；预检拦截。
3. **版本号**：导入后 version 1→2，`/api/banks` 的 version 只用于人看，无兼容影响。
4. **图片体积**：12 张共 2.4MB（其中 2 张 SHA256 相同），移动端首访图片题会多下载几百 KB；不影响正确性。
5. **本地环境坑（供他人复现）**：8788/8791 端口已被其他成员的 dev 占用（我最早两次请求打到了别人的 server）；用自己的端口 + 独立 `--persist-to`，且静态资源必须起在 Worker CORS 白名单内的源（`localhost:3100`/`127.0.0.1:3000`），否则浏览器侧 `Failed to fetch`。`d1 execute` 与 `wrangler dev` 必须指向同一个绝对 `--persist-to`。
6. **生产与 `banks/` 的内容漂移（见 7.1）**：id 69 的答案/解析两边不一致，且**生产版是错的**；本批用单题编辑修正（第 8 节），不做整库重导。
