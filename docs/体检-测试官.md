## 六、问题登记（只登记，未修改）

### P1-1 收藏按钮高亮永远不生效（数字/字符串 id 类型不一致）
- 位置：`js/quiz-renderer.js:156`（渲染时 `Storage.isBookmarked(bankId, question.id)`）+ `js/storage.js:393-395`（`includes` 严格相等）
- 现象：点击收藏后 `quiz_bookmarks` 已写入 `["1"]`，但按钮 `.btn-bookmark` 始终无 `active` 类，星标不点亮；`Quiz.render()` 重渲染、切题往返后仍不亮
- 原因：渲染传入的 `question.id` 是数字 `1`，而通过 `onclick="Quiz.toggleBookmark('1')"` 落库的是字符串 `"1"`，`includes(1)` 与 `["1"]` 永不相等
- 影响：数据与云同步正常，纯视觉反馈缺失；反向调用（数字 id 调 `toggleBookmark`）会重复 push 同一题，造成收藏数组重复
- 复现：`.tmp-test/probe.mjs` 输出 `BOOKMARK afterClick: cls="btn-bookmark " stored={"smoke-c":["1"]}`、`afterRender()`/`afterNav` 仍无 active

### P1-2 本地 dev 的 API 硬编码生产域名，开发环境没有隔离
- 位置：`js/api.js:15` `BASE_URL: 'https://ks-api.mutx.ccwu.cc'`；`js/admin.js:830` 用同一 `API.BASE_URL`
- 影响：`npm run dev` 下任何注册/同步/后台写操作都会直接落到**生产 D1**；本次体检只能用 CDP 拦截重写来规避（113 次全部改道本地 8788）
- 建议方向（仅建议）：dev 用 `import.meta.env.DEV` 指向本地 worker，或 vite proxy 掉 `/api`

### P1-3 本地 D1 旧库结构漂移（生产是否同款未验证）
- 证据：`npx wrangler d1 execute ks-leaderboard --local --command "PRAGMA table_info(users)"` 显示本地旧库 `users` 只有 `id/initials/created_at/created_device/settings/progress/last_sync_at`，缺 `bookmarks/is_admin/banned`
- 直接后果：第一次尝试造种子时报 `X [ERROR] table users has no column named bookmarks: SQLITE_ERROR`，旧环境注册/同步会 500
- 原因（经后端官第 2 阶段纠正）：**不是「没有迁移机制」**——仓库有 `worker/migrations/0002/0003/0004`，`0003_add_bookmarks.sql` 正是 `ALTER TABLE users ADD COLUMN bookmarks`。真问题是**迁移链不可从零重放**：缺 0001 基线、`0003` 在现 `schema.sql`（已含该列）上执行会撞 `duplicate column name: bookmarks`，且本地 `worker/.wrangler` 这份旧库从未跑过迁移
- 生产状态：**未验证**。生产 D1 只读 `PRAGMA` 因本机 wrangler 未登录、无 `CLOUDFLARE_API_TOKEN` 而无法执行（后端官实测 `wrangler whoami` → `Not logged in`）；本报告只声明「本地实例缺列」，不下生产结论
- 本次处置：改用独立 `--persist-to .tmp-test/d1` 全新库，未动既有 `worker/.wrangler` 状态

### P2-1 项目根目录内的临时目录会拖垮 dev server
- 现象：把 Chrome profile 放在 `C:\cursor\ks\.tmp-test\profile` 后，vite 文件监听扫到 `GPUPersistentCache\...\cache.db`，报 `EBUSY: resource busy or locked` 并**整个 dev server 退出**（exit code 1）
- 影响：代理/自动化若在项目根写被锁文件，会让 `npm run dev` 崩溃；属工作方式风险，不是产品 bug
- 处置：profile 移到 `%TEMP%\ks-smoke-*`；建议约定 `.tmp-*/` 只放文本产物

### P2-2 `quiz-core.js:140` 未注册硬闸门
- 未注册用户进刷题页会被 `redirectAfter` 踢回 `index.html`，提示只有 1.5s toast；回首页后出现注册弹窗引导（已观察到）
- 属既设计行为，仅登记：若产品希望「先试做再注册」，这里是唯一入口闸门
