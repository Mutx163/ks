## 6. 两处缺陷（需修）

### D1（必修）后台「赛季管理」点击无反应

- **复现**：登录后台 → 点「赛季管理」tab → 页面停在「总览」，`location.hash` 变成 `#/overview`，`Admin.renderSeasons` 仍是 `undefined`，赛季区空白。
- **根因**：`js/admin.js` 的 `hashForTab()` 映射表**没有 `seasons` 键**（只有 9 个旧 tab），`switchTab('seasons')` → `navigate('#/overview')` → 路由回总览。`handleRoute` 的 `valid` 白名单里有 `seasons`，所以**地址栏直达 `#/seasons` 能正常打开**——这条反而证明模块和接口都是好的，只差映射表一行。
- **修法**：`hashForTab` 的 map 加 `seasons: '#/seasons'`（1 行）。
- 证据：`.tmp-season/dbg-admin3.mjs` 输出 `afterClick:{tab:"overview",hash:"#/overview",rows:0}`；`afterHash:{tab:"seasons",rows:2}`。

### D2（必修）分析/趋势页「本地累计数据…」重复显示

- **复现**：打开分析页，同一句话出现 **2 次**；每重渲染一次再加 1 条（实测 2 → 3 → 4）。
- **根因**：`js/insights.js:102-109` `renderSeasonNote()` 每次都用 `insertAdjacentElement('beforebegin', note)` 新插一个 `<p>`，没有先删旧节点。
- **修法**：插入前移除同类节点（如 `el.parentElement.querySelectorAll('.insight-subtle.season-note')`），或渲染时整体替换容器。
- 证据：`.tmp-season/shots/note-duplicate.png`（4 条重复）、`.tmp-season/a3b.log`。
