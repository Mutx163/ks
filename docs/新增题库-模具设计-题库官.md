   某PP仪表罩采用注射成型，原设计存在以下问题：壁厚为1.5 mm、3.5 mm、1.5 mm的突变结构；内转角为R0.2 mm尖角；整个侧壁无脱模斜度；有一个深度为孔径5倍的盲孔；金属嵌件边缘为尖角，嵌入深度小于凸台高度。
   1. 壁厚突变
   • 问题：1.5 mm与3.5 mm相差超过一倍，冷却速度和收缩率不同，易产生缩孔、凹陷、翘曲和内应力。
   • 改进：将厚壁处挖空或改为加强筋结构，使主壁厚尽量接近1.5～2.0 mm；必要时应设过渡斜面或圆弧，避免壁厚突变。
   • 校核：各部分壁厚差别宜控制在30%以内；用加强筋代替厚壁时，筋厚取主壁厚的0.5～0.7倍，筋根设圆角。
   2. 尖角
   • 问题：R0.2 mm内转角接近尖角，应力集中明显，熔料流动阻力大，塑件易开裂，模具尖角处也易磨损。
   • 改进：内转角圆角半径一般取R≥0.5t（t为主壁厚），重要受力部位可增大到1.0t；外转角与之协调。
   • 效果：降低应力集中，改善充模和冷却，延长模具寿命。
   3. 无脱模斜度
   • 问题：侧壁与脱模方向平行，塑件抱紧型芯，脱模困难，易拉伤、顶白、变形甚至开裂。
   • 改进：沿脱模方向设置1°～2°（约1/30～1/60）脱模斜度；深腔、表面粗糙或收缩大的部位取较大值。
   • 注意：斜度应设在不妨碍装配的一侧，并与分型面、型芯结构协调。
   4. 深盲孔
   • 问题：孔深为孔径5倍，型芯细长，受熔体冲击易弯曲、折断，孔底易滞料，脱模阻力大。
   • 改进：尽量减小孔深或增大孔径；采用阶梯孔、两端对接型芯或先成型浅孔后机加工；必须成型时，型芯应加粗、设支撑，并保证冷却和排气。
   • 工艺：提高孔底圆角、适当增加脱模斜度，避免型芯偏心。
   5. 金属嵌件
   • 问题：嵌件边缘尖角易产生应力集中，塑料冷却收缩时可能开裂；嵌入深度小于凸台高度，嵌件固定不牢，易溢料或脱落。
   • 改进：嵌件嵌入部分周边倒角或圆角；嵌入深度应大于凸台高度；嵌件高度不宜超过其直径的2倍；外螺纹嵌件应在无螺纹部分与模具配合。
   • 模具：嵌件在模内应定位准确、防止溢料；必要时预热嵌件，减少收缩应力。
   6. 综合评价
   • 改进后塑件壁厚均匀、圆角合理、脱模顺畅，可减少缩孔、翘曲、开裂和拉伤。
   • 模具结构可简化：避免不必要的侧抽芯和镶拼；型芯强度提高，冷却和排气更易布置。
   • 成型工艺窗口扩大：注射压力、保压压力和冷却时间更易控制，废品率降低。
