# 国内免费静态托管平台调研（2026-11-16）

- 目的：回答「除了现用的腾讯 EdgeOne Pages，还能部署到哪些国内免费、速度快的平台」
- 方法：官方文档/定价页取证 + 本机 TTFB 实测（只读，不起服务、不碰生产）
- 现状基线：主站 `ks.mutx.ccwu.cc` 已由 **EdgeOne Makers**（global 节点）托管，响应头 `server: edgeone makers`，无 `cf-ray`
- 核实标记：✅ 官方页面直接读到；⚠ 公开资料/第三方口径，官方页未直接读到；❓ 未能核实

---

## 0. 结论先行

1. **免费 + 国内快 + 不用备案，三者不可兼得。** 真正的国内加速（大陆节点）几乎都要求域名完成工信部 ICP 备案；不备案只能走海外/全球节点，国内 TTFB 和 Cloudflare 差距没有想象中大。
2. **本机实测**：现用 EdgeOne 主站 TTFB **1.41–1.73s**；Cloudflare Pages **1.58–3.35s**；而国内云厂商的文档站（CloudBase/华为/阿里/又拍/CODING）**0.2–0.7s**。差距主要来自「大陆节点 vs 海外节点」，不是平台本身。
3. **静态前端可以换，后端 Worker + D1 换平台等于重写。** 所以现实方案只有两种：① 前端换国内 CDN，API 仍走 Cloudflare（跨域 + API 延迟仍在）；② 整体迁后端（D1 导出 + Worker 改写，工作量大）。
4. **没有明显优于 EdgeOne 的「免费 + 国内快」替代**：CloudBase 免费额度很小（静态容量 1GB、外网出流量 4GB/月）；七牛/又拍只有 10GB 存储 + 10–15GB/月流量且要备案；Gitee Pages 已下线；阿里/华为/百度对象存储没有永久免费额度。
5. **如果目标是「国内明显更快」，最值得做的不是换平台，而是：给 EdgeOne 项目选大陆/含大陆区域（需备案）**，或把域名备案后接阿里云 OSS+CDN/七牛。只换静态托管而不解决 API，收益有限——本机实测 API TTFB 仍有 **1.4–4.5s**。

## 4. 按「国内速度 + 零成本 + 备案可行性」排序

**前提**：假设域名**没有** ICP 备案（如有备案，排序会变，见下节）。

1. **EdgeOne Makers（现状，保持）**——已是免费、已上线、支持 Vite 与 Git/CLI、无需再折腾；global 节点下本机 TTFB 1.4–1.7s，虽不惊艳，但比 Vercel/Netlify/CF Pages 稳定。**没有明显更优的免费替代时，不折腾就是最优。**
2. **腾讯 CloudBase 静态托管**——同厂生态、部署方式多，但个人版静态容量 1GB、外网出流量 4GB/月，按当前站点体量（dist 约 4.4MB、单页 90–130KB 传输）勉强够小流量；换它收益主要是「腾讯国内节点」，仍需备案域名。
3. **七牛云 / 又拍云（二选一）**——10GB 存储 + 10–15GB/月流量，纯静态够用；但对象存储式托管，缓存/HTTPS/域名配置比 EdgeOne 麻烦，且必须备案；适合「已有备案域名 + 想极致省钱」。

> 阿里云 OSS+CDN 国内速度最好一档，但**没有永久免费额度**，按量计费；如果愿意每月花几块钱且域名有备案，它是最稳的国内方案。华为/百度对象存储同理。

## 5. 如果域名已有备案：排序会变

- **第一选择变成「EdgeOne 项目切大陆/含大陆区域」**：同一平台、同一套部署，只改加速区域 + 绑备案域名，收益最大、迁移成本最低。
- 第二选择：阿里云 OSS + CDN（国内节点质量最好，成本按量，几元/月起）。
- 第三：七牛/又拍/CloudBase。

**备案是硬门槛**：没有备案，大陆节点一律不可用；「免费 + 国内快」的免费额度再大也落不了地。

## 6. 混合架构（前端国内 + 后端 CF）的真实代价

现状：前端调 `https://ks-api.mutx.ccwu.cc/api/*`（Cloudflare Worker + D1），Worker CORS 白名单只有 `ks.mutx.ccwu.cc`、`ks-cjx.pages.dev`（`worker/src/index.js:17-19`）。

换任何新前端域名，必须：
1. **改 Worker `ALLOWED_ORIGINS` 并部署**（一次生产写；未知 Origin 会回退到白名单第一个，浏览器直接拦，页面空状态）。
2. **API 延迟不变**：本机实测 API TTFB 1.4–4.5s，刷题取题、同步、排行榜仍要跨到 Cloudflare；静态托管再快，用户点「开始刷题」仍要等 API。
3. **跨域预检**：每个非简单请求多一次 OPTIONS 往返，弱网下体感更明显。
4. **D1 不能搬**：换阿里/腾讯/七牛都要换数据库（导出/导入 + SQL 方言 + 函数改写），工作量是「重写后端」，不是「改配置」。

结论：**只换静态托管，收益主要是首屏 HTML/CSS/JS；数据交互的体感提升有限。** 想真正解决国内慢，优先级应是：备案 + 大陆节点（静态）> API 就近化（重写后端）> 换静态平台。

## 7. 建议（给 ks）

1. **本批不迁**：EdgeOne Makers 已经是「免费 + 免备案（global）+ 支持 Vite」里最省事的选择；没有证据表明换到 CloudBase/七牛能显著更快。
2. **先确认备案**：`ccwu.cc` 是否有 ICP 备案。有 → 把 EdgeOne 项目切到大陆/含大陆区域（成本最低、收益最大）；没有 → 现状态已是最优，不建议为「免费」折腾。
3. **若坚持要国内节点又没有备案**：唯一合规路径是先备案（个人可备，周期通常 1–3 周），期间不要切主域。
4. **API 是瓶颈**：如果用户主诉是「刷题慢」，优化 API（缓存、就近节点、减少请求）比换静态托管更有效；这需要另开一批评估。
5. **不要选**：Gitee Pages（已下线）、CODING Pages（状态不明）、阿里/华为/百度对象存储当「免费」用（无永久免费）。
